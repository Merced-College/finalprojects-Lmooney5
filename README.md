# cpsc39-finalProjects

Classes Created:

Flashcard
FlashcardManager

I started building my Study Flashcard App by creating the core classes for the project. The Flashcard class stores the question, answer, and topic for each flashcard, including constructors and methods to access and modify the data, amd the FlashcardManager class manages a collection of flashcards using an ArrayList and includes methods to add, remove, and display flashcards.

These classes are the foundation of the program, and will be used later to implement features like quiz mode and file saving.
